# Create the worker/ package skeleton

Create the new top-level `worker/` folder as an independent npm package, `deku-swarm`, following the same layout `clients/node/` uses. This step only creates the skeleton (package manifest, tooling config, empty `lib/index.js`) — the actual code move happens in the next step, so the two are easy to review separately.

```
worker/
├── package.json              # name: deku-swarm, version: 1.6.2, type: module
├── lib/
│   └── index.js               # re-exports public API (filled in as files land in step 03)
├── spec/                      # mirrors lib/, populated in step 03
│   └── support/
│       └── jasmine.json
├── eslint.config.mjs
├── yarn.lock
└── README.md
```

`worker/package.json`:

```json
{
  "name": "deku-swarm",
  "type": "module",
  "version": "1.6.2",
  "description": "Queue-based worker pool with retry, cooldown, and job chaining support",
  "main": "lib/index.js",
  "files": ["lib"],
  "scripts": {
    "spec": "npx jasmine --config=spec/support/jasmine.json",
    "test": "npx c8 jasmine --config=spec/support/jasmine.json",
    "coverage": "npm run test",
    "lint": "npx eslint lib spec",
    "report": "npx jscpd lib spec"
  }
}
```

Base `eslint.config.mjs`, `spec/support/jasmine.json`, and `devDependencies` (jasmine, c8, eslint, jscpd) on `clients/node/`'s equivalents — same Node/ESM conventions, no Navi-specific rules. `README.md` starts as a short placeholder; a full write-up is not part of this plan (out of scope — the package isn't published to a wide audience yet).

## Files to Change

- `worker/package.json` — new file, as shown above.
- `worker/lib/index.js` — new file, empty export list for now (populated in step 03).
- `worker/eslint.config.mjs` — new file, copied/adapted from `clients/node/eslint.config.mjs`.
- `worker/spec/support/jasmine.json` — new file, copied/adapted from `clients/node/spec/support/jasmine.json`.
- `worker/README.md` — new file, short placeholder.
- `worker/yarn.lock` — generated by `yarn install` after `package.json`/`devDependencies` are in place.

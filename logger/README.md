# deku-sprout

Shared logging package for [Navi](https://github.com/darthjee/navi) and its clients.

`deku-sprout` is being extracted from the logging code currently duplicated between `source/` and `clients/node/`, following the same standalone-package model as [`deku-swarm`](https://github.com/darthjee/navi/tree/main/worker). It lives under [`logger/`](https://github.com/darthjee/navi/tree/main/logger).

---

## Installation

```bash
npm install deku-sprout
```

## Status

This package is still being scaffolded — no logging classes are published yet. Check back once the real implementation lands.

For what's coming, see the [`deku-sprout` spec](../docs/agents/specs/deku-sprout.md).
